# Goals & Principles

## Why Waypoint

Linux file managers each have part of the answer. Nemo is calm and practical. Dolphin is deep but dense. Nautilus is clean but pared back. None of them treats tabs, drag and drop, and remote locations as one connected system, and none of them looks at home in the Liminal HQ family. Waypoint aims to be the file manager you keep open all day.

## Goals

1. **Everywhere feels local.** Remote, archive, git and cloud locations browse, drag and preview like `~/`.
2. **Drag and drop you can trust.** You always know the action before you release, and every drop can be undone.
3. **Tabs are workspaces.** You can tear them off, merge, pin, group, split and restore them.
4. **Extensible without being fragile.** Plugins are sandboxed, have declared permissions, and fail gracefully.
5. **Native on every desktop.** It respects the OS scheme, accent and icon theme, and it's transparent when you want it to be.
6. **Keyboard parity.** Anything you can do with a mouse, you can do from the keyboard or the palette.

## Principles

- **Calm by default, power on demand.** The default window is simple. Panels, split, terminal and shelf stay out of the way until you call for them.
- **Show the outcome before it happens.** Drag badges, rename previews and conflict diffs all do this.
- **One pattern, many places.** The same context menu, the same ops queue, the same connect flow, whatever the provider.
- **Family first.** Reuse the Liminal title bar, context menu, tokens and type. Nothing should be designed twice.
- **The OS wins ties.** When OS theming is on, the portal's colour scheme and accent override brand tokens.
- **Nothing lost.** Undo covers file ops, sessions restore, and the Shelf persists.

## Non-goals

Desktop icons, built-in editing, offline sync, AI features, and replacing a terminal.

## Design tone

Quiet surfaces with generous, readable type. The accent is used only for focus, selection and live action. Motion is short and purposeful (120–200 ms), and spring feedback on drag is subtle. Brand warmth comes from the ember accent and Space Grotesk headings, not decoration.
