| D89  | Window frame and shadows                                     | The OS draws the window shadow wherever it will: Windows (and macOS) keep `shadow: true`, so DWM also rounds Windows 11 corners and the CSS drops its own radius there (detected by build number 22000 and up; Windows 10 has no native rounding, so it keeps the CSS radius). | D90  | Always on Top and the system window menu                     | Where the compositor cannot honour Always on Top (Wayland, which has no protocol for it; Tauri only echoes the request), the pin and the menu item are hidden. The custom menu keeps its look; the OS's advanced actions stay one entry away. Windows and X11 keep the pin, and follow the window manager's real state: on X11 the plugin reads `_NET_WM_STATE_ABOVE` and emits a change event, so the pin stays right when the compositor's menu changes it.                                                                                                                                                                                                                                                                                                                                                                                                                                        |
