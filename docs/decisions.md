| D128 | Sort and group the folder listing                                            | Grouping is part of the sort: `SortSpec` gains `groupBy` (none, kind, modified, size, name, type), so it travels `set_sort`, the open options and the saved view, and a sort saved without it reads as ungrouped. Groups are the first key of the order, so each is one contiguous run and the sort orders the rows inside it; a group column that is also the sort column follows its direction, and with Folders first the Folders group of Kind and Type stays on top. Rust works the runs out of the sorted view (`GroupRun`, a typed `GroupKey` such as a size band or a modified bucket plus its value) and sends them whole with the snapshot, with every `Changed` event and with the scan's last `Progress` event: boundaries are recomputed after a patch instead of patched, because a row that changes group moves with its header and a header can appear or go. Modified bands are local calendar days, weeks start on Monday, and the index fixes one clock until it is rebuilt, so the order cannot shift under a patch.
