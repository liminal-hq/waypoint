| A18 | Accepted (2026-09-30) | **Milestone 0 spikes 1 and 5 results and the rules they set**: 60 Hz scrolling, instant jumps and near-instant selection on a 500 000-row listing in WebKitGTK (Wayland and XWayland), and 500 000 entries scanned in about 0.6 s over a `Channel`. The design must (1) cope with the webview's scroll-height cap of 33 554 428 px, about 1.198 million rows at 28 px, by scaling the scroll position for larger listings; (2) end every stream with an explicit message carrying a count, because channel messages can arrive after the command returns; (3) show placeholder rows during a fling, since at about 700 rows a frame the page fetch cannot keep up; (4) batch scans at about 2 000 to 5 000 entries; and (5) send typed JSON pages, not raw bytes, below a few thousand rows. | Full figures, caveats and what was not covered (WebView2, native X11, cold and network filesystems, a maximised window, the React Compiler) are in [`milestone-0-spikes.md`](milestone-0-spikes.md). Spikes 2 to 4 are still to run.                                                                                                                                                                                                                                                                                                                                      |
| A19 | Accepted (2026-09-30) | **Entries and locations have stable, lossless identity.** Every listing entry carries a listing-scoped `EntryId` (a `u32`, so a JavaScript `number`) and a display name; the wire never sends raw file-name bytes, and operations name `(handle, EntryId)` so Rust resolves the real path. Selection is a frontend model keyed by `EntryId`. Anywhere a path travels (history, tabs, favourites, breadcrumbs, Go to…) it is a `Location` with a lossy `display` and a lossless `uri` (a percent-encoded `file://` URI for local paths), and `waypoint-path` is the scheme-shaped type with only `file` implemented.                                                                                                                                                                          | File names are not always valid UTF-8 on Linux, and selection has to survive re-sorts and live updates. Plan decisions 2 and 3 for milestone 2.                                                                                                                                                                                                                                                                                                                                                                                                                           |
| A20 | Accepted (2026-09-30) | **Tab state lives in Rust, starting with a minimal `waypoint-session`.** Milestone 2 builds a pure reducer for tabs, order, active tab and per-tab history, with a thin plugin; groups, pairs and persistence come in milestone 3. The frontend `TabsApi` is a snapshot with a revision plus granular events.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | README §4 already places tab state in `waypoint-session`, and tab-to-handle ownership (closing a tab closes its listing) needs Rust anyway. A temporary frontend store would be rewritten in milestone 3. Confirmed by the owner (2026-09-30).                                                                                                                                                                                                                                                                                                                            |
| A21 | Accepted (2026-09-30) | **Domain wire types generate into `packages/protocol`.** Every `ts-rs` type in `waypoint-protocol` and the domain crates (`waypoint-vfs`, later `waypoint-session` and the rest) exports to `packages/protocol/src/generated/`, a private types-only workspace package (`@liminal-hq/waypoint-protocol`). The app and each domain plugin's `guest-js` import from it by package name. Reusable plugins keep exporting into their own `guest-js/bindings` and never import from it.                                                                                                                                                                                                                                                                                                           | `ts-rs` writes relative imports between export directories, so a type in a plugin's bindings importing a shared type from the app's source tree cannot be packaged. One shared package keeps every import inside a package boundary and scales to each future domain crate. | A22 | Accepted (2026-09-30) | **Sorting, kind and symlinks.** Sorting is natural ordering (digit runs compare as numbers) over Unicode case folding, with directories first as a setting and a cached sort key per entry; ICU collation is a later setting. `Entry.kind`, the symlink target's kind and the icon group are decided in Rust, and symlink targets are resolved at scan time so directories-first is correct (with a bounded background pass for pathological counts). "Symlink" is defined per platform: a Windows reparse point is not necessarily one.                                                                                                                                                                                                                                                     | The milestone 0 spike sorted 500 000 names in 169 to 187 ms with an ASCII comparator; natural ordering is slower, hence the cached keys (A18). Directories-first needs every kind before the index is built.                                                                                                                                                                                                                                                                                                                                                              |
